## How I build

- Start with the business workflow and measurable outcome, not the fashionable tool.
- Keep permissions, data lifecycle, failure paths, and maintainability visible in the design.
- Build the smallest valuable slice, test it against real behaviour, then deepen the system.
- Use AI for bounded assistance while deterministic rules protect critical decisions.
